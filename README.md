# codewithquality.com — Portfolio

Personal portfolio of **Satheeshkumar Raman**, Senior Quality Assurance Engineer.

Live site: https://codewithquality.com

## Stack
Static HTML/CSS/JS built on the [iPortfolio](https://bootstrapmade.com/iportfolio-bootstrap-portfolio-websites-template/) template by BootstrapMade (Bootstrap 5). No build step.

## Local preview
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Deploy
Hosted on HostGator. Every push to `main` deploys automatically via GitHub Actions (`.github/workflows/deploy.yml`).
